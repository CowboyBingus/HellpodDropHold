# Hellpod Drop Hold

Hellpod Drop Hold now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Hellpod Drop Hold's C source is in
[`src/components/hellpod_drop_hold`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/hellpod_drop_hold).

The standalone Lua mod (v1.2.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/HellpodDropHold/tree/legacy) branch. Its releases and tags are unchanged.
