Hellpod Drop Hold - v1.2

Release for Steam build 25480438 / EXE 1.8.46015.0. Held the pod in two live joins.

Joining a mission in progress, or loading slowly, no longer costs you the drop. Your
hellpod waits in the sky until the loading screen and the join cutscene are gone, and
is already falling when you see it, like a normal drop, with steering near the ground.

Requires Bingus Shared Loader v18 or newer / API 1, installed separately:
https://github.com/CowboyBingus/BingusSharedLoader/releases/latest

With the game closed, import the Bingus Shared Loader ZIP and
Hellpod-Drop-Hold-v1.2.zip into Arsenal or HD2MM, then enable and deploy both.
Use one manager. Keep the loader enabled; managers do not install it automatically.
Only the player who installs it needs it: teammates and hosts without the mod see
your hellpod wait in the sky.

To uninstall, disable this mod, purge deployment, and redeploy the remaining mods.
Remove Bingus Shared Loader only if no dependent mods remain enabled.

Logs: %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\HellpodDropHold.log
